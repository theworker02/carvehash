# carvehash

Carve encode/decode helpers for hash payloads in pipelines.

**Site:** https://theworker02.github.io/carvehash/

## Install / run

```bash
git clone https://github.com/theworker02/carvehash.git
cd carvehash
node src/cli.js
node --test
```
